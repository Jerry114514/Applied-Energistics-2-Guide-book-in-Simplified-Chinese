# 迷你 TNT

迷你 TNT 是用于小爆炸的小型 TNT。对于制作量子缠绕态奇点<ae2:quantum_entangled_singularity>对非常有用。

如果你想在服务器上禁用 TNT 和苦力怕，可以在配置中禁用其方块破坏功能，以便在不造成破坏的情况下制作奇点。

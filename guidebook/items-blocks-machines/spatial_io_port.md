# 空间 IO 端口

空间 IO 端口用于[空间 IO](../ae2-mechanics/spatial-io.md)中，用来容纳[空间元件](spatial_cells.md)并控制空间 IO 操作。  

如果你想要自动化它，元件可以通过任何物品物流方式（如漏斗或 AE2 总线）插入和提取。

# 显示元件

显示元件用于过滤[终端](terminals.md)的显示内容。  

你要在元件工作台<ae2:cell_workbench>中对它们进行分区。  

例如，假设你想要一个只显示一组石头建筑材料的终端。将显示元件分区为那些材料并放入终端中，就只会显示那些物品。  

显示元件是累加的，如果你有一个用于橡木木板的显示元件和一个用于圆石的显示元件，将两者都放入会同时显示木板和圆石。

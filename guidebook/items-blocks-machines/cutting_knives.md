# 石英工具

切割刀用于制作名称压印模板<ae2:name_press>和线缆锚<ae2:cable_anchor>。  

要合成名称压印模板，请右键点击切割刀并插入一块金属锭，然后你需要输入你希望刻在板上的名称，之后直接提取制作完成的板即可。
